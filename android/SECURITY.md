# Security notes

Please report vulnerabilities privately to the repository owner before opening
a public issue with exploit details.

The Android client intentionally supports legacy cleartext FTP for compatible
servers. FTP does not protect credentials or file contents; prefer SFTP or FTPS.
FTPS enables TLS endpoint verification. SFTP pins the server's SHA-256 host-key
fingerprint after explicit first-use approval and rejects a changed key.

Saved passwords and per-profile terminal hotkey payloads are encrypted with
AES-GCM using a non-exportable key generated by Android Keystore. The
application does not log passwords or terminal traffic and does not include
analytics, advertising, crash-reporting, or telemetry SDKs.

Connection profiles, server addresses, pinned fingerprints and terminal
hotkeys are created at runtime in app-private storage. They are not part of the
repository. Git ignore rules cover desktop `sites.json`, Android
`local.properties`, environment files, private keys and private signing
keystores.

`signing/community-release.p12` and its credentials are deliberately public.
They identify a community-compatible build, not a trusted publisher. Anyone
can sign an APK with this key. Official store releases must override all four
`KREOSFTP_KEYSTORE_*` environment variables with a privately held key.

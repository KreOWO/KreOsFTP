# KreOsFTP для Android

Открытый Android-порт KreOsFTP. Это самостоятельный проект Gradle: папку
`android` можно открыть как проект в Android Studio и собрать без исходников
Electron-приложения.

## Что уже работает

- FTP, явный FTPS и SFTP;
- две файловые панели (друг под другом в портретном режиме и рядом в
  альбомном);
- выбор локальной папки через системный Storage Access Framework — приложению
  не нужен полный доступ ко всему накопителю;
- загрузка и скачивание отдельных файлов и каталогов;
- до трёх независимых передач одновременно;
- обновление сервера и локальной папки с подтверждением;
- `.ftpignore` с правилами в стиле `.gitignore`; сам `.ftpignore` никогда не
  передаётся;
- сравнение при синхронизации по наличию и размеру, без скачивания файлов ради
  хеширования; файлы на стороне назначения не удаляются;
- пароли профилей шифруются AES-GCM ключом из Android Keystore;
- для SFTP используется закрепление SSH host key: при первом подключении
  показывается SHA-256 отпечаток, при изменении ключа подключение отклоняется;
- интерактивный SSH-терминал с настоящим PTY `xterm-256color`, ANSI-цветами,
  перемещением курсора, alternate screen и передачей нового размера окна;
- экранная и физическая клавиатура, системное копирование и вставка, служебные
  клавиши Esc, Tab, стрелки, Ctrl+C, Ctrl+D и Ctrl+Z;
- пользовательские кнопки и сочетания физической клавиатуры. Хоткеи задаются
  отдельно для каждого подключения и хранятся в зашифрованном виде.

Android-порт пока не содержит докачку с прерванной позиции и drag-and-drop
настольной версии. Настольные макросы подключения, синхронизации и SSH-команд
также пока доступны только в Electron-клиенте; на Android есть отдельные
экранные кнопки и хоткеи терминала.

## SSH-терминал и хоткеи

В профиле укажите SSH-порт (по умолчанию `22`) и нажмите **SSH** в верхней
панели. Терминал использует тот же сервер, имя пользователя и пароль. При первом
подключении обязательно сверьте отпечаток ключа.

Кнопка **⌨** открывает редактор хоткеев. Каждый хоткей может одновременно иметь
экранную кнопку и необязательное сочетание физической клавиатуры. В отправляемой
последовательности поддерживаются `\e`, `\r`, `\n`, `\t` и `\xNN`; например,
`\x03` отправляет Ctrl+C. Команды хоткеев шифруются тем же ключом Android
Keystore, что и пароль профиля.

## Сборка в Android Studio

Требования: Android Studio с JDK 17 или 21 и Android SDK 36. Минимальная версия
устройства — Android 8.0 (API 26).

1. Выберите **File → Open** и откройте папку `android`.
2. Дождитесь Gradle Sync. Версия Gradle зафиксирована wrapper-файлами проекта.
3. Выберите конфигурацию `app` и нажмите **Run**, либо **Build → Build APK(s)**.

Сборка из терминала:

```powershell
cd android
.\gradlew.bat testDebugUnitTest assembleDebug
```

На Linux/macOS используйте `./gradlew`. Debug APK появится в
`app/build/outputs/apk/debug/app-debug.apk`.

Для готовой подписанной release-сборки:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleRelease
```

Подписанный APK появится в `app/build/outputs/apk/release/app-release.apk`.

## Подпись community-сборки

Проект полностью собирается сразу после клонирования: открытый community-key
уже лежит в `signing/community-release.p12`, а его параметры — в
`keystore.properties`:

| Параметр | Значение |
| --- | --- |
| Store password | `kreosftp` |
| Key alias | `kreosftp` |
| Key password | `kreosftp` |

Это намеренно публичный ключ для локальной разработки, CI и сборок сообщества.
Он позволяет устанавливать новые community-сборки поверх предыдущих, но **не
удостоверяет автора**: любой человек с репозиторием может подписать им APK с тем
же package id. Не публикуйте приложение в Google Play или другом официальном
магазине с этим ключом.

Для официального релиза задайте собственный закрытый keystore без изменения
исходников:

```powershell
$env:KREOSFTP_KEYSTORE_FILE='<path-to-private-keystore>'
$env:KREOSFTP_KEYSTORE_PASSWORD='strong-store-password'
$env:KREOSFTP_KEY_ALIAS='release'
$env:KREOSFTP_KEY_PASSWORD='strong-key-password'
.\gradlew.bat assembleRelease
```

Файлы `*.jks`, `*.keystore` и `*.p12` игнорируются Git; единственное исключение
— явно открытый `signing/community-release.p12`.

## Безопасность

- Выбирайте SFTP или FTPS. Обычный FTP передаёт пароль и данные без шифрования;
  перед таким подключением приложение показывает предупреждение.
- Перед первым SFTP- или SSH-подключением сверьте показанный отпечаток ключа с
  администратором сервера.
- Профили и URI выбранной папки остаются в приватном хранилище приложения.
  Пароль и команды хоткеев дополнительно шифруются ключом, который не покидает
  Android Keystore.
- Профили, пароли, отпечатки серверов и хоткеи создаются только во время работы
  приложения и не находятся в репозитории. `local.properties`, приватные
  keystore и файлы окружения исключены правилами Git.
- В проекте нет аналитики, рекламы, телеметрии и разрешений на контакты,
  геопозицию или общий доступ к накопителю. Требуется только `INTERNET`.
- Публичный community signing key предназначен только для воспроизводимых
  сборок. Для официального распространения используйте собственный закрытый
  ключ через переменные окружения.
